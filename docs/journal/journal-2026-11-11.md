## M16: Identity, Title and Game Over (T109–T112)

M16 gives 9dle B's palette, faces and focus ring. It adds one top bar on
every screen and a geometry sweep over every gallery state, and puts the
title and both game-over variants in B.

### Decisions made during execution

- **`ActionButton` takes a `className`,** so each screen sets its own button
  heights and type (R1). The override wins because each screen's
  stylesheet is emitted after `ActionButton`'s, at equal specificity. Class
  order has nothing to do with it.
- **The bar is a `1fr auto 1fr` grid, not flex with `space-between`.** With
  Back and the toggle at different widths, flex left the label 7–11 px off
  centre.
- **A `KNOWN_MISSES` key names the engine** when a state misses in only one
  of them. None does: Chromium and WebKit miss the same states by the same
  heights.
- **Reduced motion and the disabled look:**
  - T109 removed the disabled action's 4 px resting offset, the old `11d`
    rise. Disabled is now flat at 45 % opacity, as the Global Constraints
    say. This is on Ori's list.
- **T109's scope widened twice:**
  - It may edit any component stylesheet that reads a token it deletes or
    renames, or that draws its own focus ring (R2).
  - It also fixes every comment its palette change made false.
- **The game-over screen** no longer draws the equation the run stopped on
  (ruling 13). `product.md` now says the reason and the row marks explain an
  early end.
